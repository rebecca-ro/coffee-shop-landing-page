# Hemlock Coffee Co.

A boutique, responsive coffee shop landing page and frontend portfolio project featuring a modern aesthetic, custom typography, dynamic e-commerce cart management, and seamless order-to-checkout form integration.

## Features

- **Interactive E-Commerce Cart:** Fully working vanilla JavaScript slide-out cart drawer, live item counter, total calculation, and dynamic item rendering.
- **Form Integration:** Dynamic checkout action that packages cart selections and auto-fills them directly into the contact message body for seamless ordering.
- **Responsive Design:** Mobile-optimized layout featuring a stacked navigation structure, fluid typography, and media query scaling.
- **Moody Boutique Aesthetic:** Dark moody hero section paired with custom button states and high-contrast accents.

## Tech Stack

- **HTML5** (Semantic markup)
- **CSS3** (Custom properties, Flexbox, Media Queries)
- **Vanilla JavaScript** (DOM manipulation, event handling, state management)
